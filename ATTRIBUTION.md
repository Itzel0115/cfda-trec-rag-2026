# Attribution and Provenance

This repository preserves a sanitized copy of code and documentation developed
by the CFDA TREC RAG 2026 team. Multiple contributors participated in the
project. The repository owner is maintaining this local archival/portfolio
copy; it does not imply sole authorship, ownership, or responsibility for all
components.

The exact contribution boundary of some files requires confirmation. In
particular, the historical sidecar implementation and checklist producer were
maintained or contributed through different team workspaces. Authorship and
provenance require confirmation before redistribution.

Third-party or externally provided categories used by the system include:

- Pyserini and the ClimbMix corpus/index service;
- TREC RAG organizer task specifications and evaluation conventions;
- Hugging Face/ONNX cross-encoder and embedding model families;
- external LLM providers and model services;
- ACL report style and bibliography tooling, if report material is later added.

Technical-report authorship and author order are preserved from the canonical
final artifact. The existence of this personal archival repository does not
change report authorship or imply sole authorship.

This file does not assert licenses. Model, dataset, organizer-material,
service, and style licenses must be verified by the team before any broader
distribution. The current staging tree excludes competition data, submissions,
caches, and report-production history; it includes the canonical final report
artifact and selected source package.
