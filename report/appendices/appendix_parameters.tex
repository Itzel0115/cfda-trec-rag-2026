\par\vspace{0.6\baselineskip}

The retained source identifiers are
\texttt{Xenova/ms-marco-MiniLM-L-6-v2} for the top-head cross-encoder,
\texttt{bge-m3} for the dense endpoint, and
\url{cross-encoder/ms-marco-MiniLM-L6-v2} for the selected deep-tail
cross-encoder. The frozen
run records do not preserve a versioned provider checkpoint for the
top-head service, so no more specific head checkpoint is asserted here.
For Retrieval, Query2Doc and facet-query generation use \texttt{gpt-5.6-sol}
at temperature 0. Query2Doc has one 400-token call and omits its route after
failure or unusable output; facet templates are schema-validated, with up to
four attempts. The Retrieval sufficiency/follow-up judge uses
\texttt{gpt-oss-120b} at temperature 0, with up to five total attempts.
Table~\ref{tab:appendix-rag-parameters} separately summarizes RAG runtime
model roles, and its prompts appear in
Appendix~\ref{app:prompts-traces}. This table is a concise summary;
stage-specific fusion and per-topic trace details are specified in the
Method and reproducibility records.
